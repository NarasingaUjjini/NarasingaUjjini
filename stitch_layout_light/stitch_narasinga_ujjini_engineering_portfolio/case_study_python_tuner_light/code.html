The Method: Fast Fourier Transform

To accurately determine pitch, the incoming raw audio stream (time domain) is continuously sliced into overlapping windowed frames. An FFT algorithm is applied to each frame, converting the signal into the frequency domain.

Peak detection algorithms then identify the fundamental frequency among the harmonic series, filtering out noise floor artifacts to provide a stable tuning readout.

def compute_fft(data, rate):
    # Apply Hanning window to reduce spectral leakage
    window = np.hanning(len(data))
    fft_data = np.fft.rfft(data * window)
    freqs = np.fft.rfftfreq(len(data), 1.0/rate)
    return freqs, np.abs(fft_data)

Why build another tuner?

Standard GUI frameworks often struggle with continuous high frame-rate rendering of large data arrays, leading to UI thread blocking and unacceptable latency for a real-time tuning application. This project served as an engineering exercise to bypass typical matplotlib bottlenecks by utilizing PyQtGraph's OpenGL-accelerated plotting, achieving a stable 60FPS refresh rate while processing 44.1kHz audio streams on moderate hardware.
